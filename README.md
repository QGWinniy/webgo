# Shop

Интернет-магазин с каталогом товаров, корзиной и оформлением заказа.

## Запуск

Исходники API и сайта монтируются в контейнеры. После изменения кода достаточно
один раз выполнить `docker-compose restart api web`: Go запустится из актуальных
файлов, без пересборки образов. `docker-compose up --build` нужен только после
изменения `go.mod`, `go.sum` или Dockerfile.

`init.sql` PostgreSQL применяет только при создании нового тома данных. Чтобы
применить его повторно, удалите том командой `docker-compose down -v`, затем
поднимите сервисы снова.

Основной функционал:

- просмотр каталога и отдельных страниц товаров;
- несколько изображений для каждого товара;
- добавление товаров в корзину и изменение их количества;
- оформление заказа с именем и номером телефона;
- отправка уведомления о заказе на электронную почту;
- хранение товаров и ссылок на изображения в PostgreSQL;
