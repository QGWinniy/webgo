# Shop

Интернет-магазин с каталогом товаров, корзиной и оформлением заказа.

Основной функционал:

- просмотр каталога и отдельных страниц товаров;
- несколько изображений для каждого товара;
- добавление товаров в корзину и изменение их количества;
- оформление заказа с именем и номером телефона;
- отправка уведомления о заказе на электронную почту;
- хранение товаров и ссылок на изображения в PostgreSQL;
